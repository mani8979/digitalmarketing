# Grow Bird — Smart Marketing. Real Growth.

A modern, production-quality digital growth agency website built with pure HTML5, modern Vanilla CSS, and modular Vanilla JavaScript.

## 🚀 Overview

**Grow Bird** is a digital growth agency helping startups, local businesses, and growing brands scale their online presence through data-backed marketing, conversion-focused websites, SEO, AI solutions, and creative branding.

## 🌟 Features

- **Outfit-Style Kinetic Intro Loader**: Expanding 3D creative showcase cards, kinetic letter reveal, and percentage growth ticker.
- **Pure White & Light Aesthetic**: Crisp, clean light surfaces, deep charcoal typography, and electric emerald + tech indigo accents.
- **Sticky Stacking Services Deck**: Native, fluid CSS sticky card deck with 8 connected services.
- **Connected Growth Ecosystem**: Interactive hub with dynamic SVG connector lines connecting business goals with 8 touchpoints.
- **Capability Matrix**: Fast interactive tab switching across Branding, Social, Web, Ads, Content, and AI.
- **Interactive Growth Estimator (ROI Tool)**: Strategy readiness assessment calculator.
- **Filterable Portfolio**: Tagged work showcases with project details modal.
- **Testimonial Carousel**: Smooth slide carousel with client feedback.
- **Lead & Consultation Modals**: Form validation, service pills, and instant toast notifications.
- **100% Responsive Design**: Full support for mobile, tablet, laptop, and 4K displays.

## 📁 Project Structure

```
digitalmarketing/
├── index.html            # Main semantic HTML markup & layout
├── css/
│   ├── main.css          # Design system tokens, color palettes & base reset
│   ├── components.css    # Buttons, navbar, modals, cards, form inputs & toasts
│   ├── sections.css      # Layouts, telemetry, sticky stack deck & ecosystem
│   └── responsive.css    # Responsive breakpoints (360px - 1440px)
└── js/
    ├── app.js            # Navbar scroll state, drawer & back-to-top
    ├── animations.js     # Intro loader & smooth interactions
    ├── ecosystem.js      # Dynamic SVG connector lines for ecosystem hub
    ├── portfolio.js      # Portfolio filter tabs & project modal
    ├── carousel.js       # Testimonials slider controls
    ├── calculator.js     # Growth readiness calculator logic
    └── contact.js        # Form validation, modals & toast alerts
```

## 🛠️ Getting Started

Open `index.html` in any modern web browser or serve locally with Python:

```bash
python -m http.server 8080
```
Then navigate to `http://localhost:8080/`.
